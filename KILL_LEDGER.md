# Saturday — kill ledger

The archive's scarce asset is not only what survived. It is also the set of branches that were already tried hard enough to die.

This file exists to stop Saturday from rediscovering dead ends under new names.

Working rule:

> Before proposing a mechanism, search both the archive map **and this kill ledger**. A dead branch may be revisited only if the new proposal changes the attacker, the task, the operator class, or the measurement in a named way.

The entries below record the strongest current reading of old negative results. They are not universal impossibility theorems unless explicitly stated as such.

## Impossibility-shaped results worth preserving carefully

### Independent real decays do not equal ROTATE

The MP2 result should not be diluted into “oscillators are one implementation among many.” The dynamical type is the **pole structure**: one damped complex-conjugate pair. A finite bank restricted to independent real decays cannot exactly realize that same mode without changing the allowed operator class; the measured approximation with many real decays required pathological cancellation and remained poor.

Saturday should therefore distinguish:

```text
TYPE / SPECIFICATION
    ROTATE = complex-conjugate pole pair

IMPLEMENTATIONS
    local complex oscillator
    real 2x2 skew plane
    coupled resonant ring / eigenplane
```

The implementations may vary. The specification is what the separation result attaches to.

## Things that are not kills

Do not incorrectly promote implementation failures into rejection of the underlying question.

- `Little_dude` does **not** show dendrites are useless; it did not build dendritic spatial dynamics.
- `FieldLatentBridge` does **not** show trajectory latents are useless; it did not maintain a trajectory.
- old brain-named modules do **not** test their biological names merely because the README used them.
- a toy losing to a GRU on one task does not prove its local mechanism is useless for scheduling, physical mapping, signal processing, or another task.
